# QuickNotes System Design & API Client

QuickNotes is a production-grade note-taking web application designed to transition from a browser-only client to a scalable cloud service supporting 1 million users.

## Features
- **Interactive API Client:** Built with vanilla JavaScript, featuring robust async request handling (`GET`, `POST`, `DELETE`), try/catch blocks, input validation, and XSS protection via `textContent`.
- **System Architecture Planning:** Comprehensive architectural specifications, ERD data models, and RESTful API endpoints designed for high availability and low latency.
